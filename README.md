# 🖱️ Hand Gesture Controlled Virtual Mouse

This project uses **OpenCV**, **MediaPipe**, and **AutoPy** to turn your hand gestures into mouse movements and clicks — no hardware required beyond a webcam!

[https://github.com/Abhranil2004/Hand-Gesture-Controlled-Virtual-Mouse](https://github.com/Abhranil2004/Hand-Gesture-Controlled-Virtual-Mouse)

---

## ✨ Features

- 👆 Move mouse with your index finger
- 🤏 Click by pinching (index + middle fingers)
- 🖥️ Works across the **entire screen**
- 🧠 Hand tracking using **MediaPipe**
- ⚡ Smooth, responsive cursor movement

---

## 🛠️ Technologies Used

- [Python](https://www.python.org/)
- [OpenCV](https://opencv.org/)
- [MediaPipe](https://google.github.io/mediapipe/)
- [AutoPy](https://github.com/autopilot-rs/autopy)
- [NumPy](https://numpy.org/)

## 🚀 How to Run

### 1. Clone the Repo

```bash
git clone https://github.com/your-username/your-repo-name
cd your-repo-name
````

### 2. Install Dependencies

```bash
pip install opencv-python mediapipe autopy numpy
```

### 3. Run the Code

```bash
python VirtualMouse.py
```

### 4. Exit

Press `ESC` to exit the program.
